# GeoTimeLapse QGIS Plugin

GeoTimeLapse is a QGIS plugin that allows users to generate time-lapse animations from satellite images, integrating data acquisition, processing, and video export into a single automated workflow.

This plugin is designed to simplify the creation of multitemporal animations, with support for different types of imagery (RGB, infrared, radar) and the ability to configure Areas of Interest (AOI) and time ranges.

For more details on how to use GeoTimeLapse, please refer to the [full documentation](https://cristian-blanco.github.io/docs-geotimelapse/).

## Key Features

- **Integration with Google Earth Engine**.
- **Area of Interest (AOI)** selection.
- **Time range** configuration.
- **Multispectral support** (RGB, infrared, radar).
- **Cloud filtering**.
- **Image normalization**.
- **Frame duration control**.
- Direct **video export**.
